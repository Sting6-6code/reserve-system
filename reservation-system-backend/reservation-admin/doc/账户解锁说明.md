# 账户锁定问题解决方案

## 问题原因

系统在 `application.yml` 配置文件中，`user.password.lockTime` 被设置为 **5000 分钟**（约 83 小时），导致账户被锁定后需要等待很长时间才能解锁。

## 已完成的修复

### 1. 修改锁定时间配置

已修改 `reservation-admin/src/main/resources/application.yml` 文件：
- **修改前**: `lockTime: 5000` (5000 分钟)
- **修改后**: `lockTime: 10` (10 分钟)

修改后，账户被锁定后只需等待 10 分钟即可自动解锁。

### 2. 创建紧急解锁脚本

已创建两个解锁脚本，用于立即清除 Redis 中的账户锁定记录：

- **Linux/Mac**: `unlock-account.sh`
- **Windows**: `unlock-account.bat`

## 立即解锁 admin 账户的方法

### 方法一：使用解锁脚本（推荐）

#### Linux/Mac 系统：
```bash
cd reservation-system-backend
./unlock-account.sh admin
```

#### Windows 系统：
```cmd
cd reservation-system-backend
unlock-account.bat admin
```

### 方法二：直接使用 Redis 命令行

1. 连接到 Redis：
```bash
redis-cli -h localhost -p 6379 -a liuhuoniu@123 -n 0
```

2. 删除锁定记录：
```redis
DEL pwd_err_cnt:admin
```

3. 验证是否删除成功：
```redis
GET pwd_err_cnt:admin
```
（应该返回 `(nil)` 表示已删除）

### 方法三：通过系统解锁接口（需要其他已登录账户）

如果系统中有其他管理员账户可以登录，可以通过以下接口解锁：

```
GET /monitor/logininfor/unlock/admin
```

需要权限：`monitor:logininfor:unlock`

## 锁定机制说明

### 锁定规则
- **最大重试次数**: 5 次（`maxRetryCount: 5`）
- **锁定时间**: 10 分钟（已修复，原为 5000 分钟）
- **锁定信息存储**: Redis，key 格式为 `pwd_err_cnt:{用户名}`

### 锁定流程
1. 用户输入错误密码
2. 系统在 Redis 中记录错误次数
3. 错误次数达到 5 次后，账户被锁定
4. 锁定信息存储在 Redis 中，过期时间为配置的 `lockTime`（分钟）

### 解锁方式
1. **自动解锁**: 等待锁定时间过期（10 分钟）
2. **手动解锁**: 删除 Redis 中的锁定记录（使用上述方法）

修复完成后，请验证：

   - 检查 `application.yml` 中 `lockTime: 10` 是否正确

2. **清除锁定记录**：
   - 运行解锁脚本或手动删除 Redis 中的锁定记录

3. **重启应用**（如果需要）：
   - 如果应用正在运行，需要重启以加载新的配置
   - 或者等待配置热加载（如果启用了 devtools）

4. **测试登录**：
   - 使用正确的用户名和密码尝试登录
   - 应该可以正常登录

## 注意事项

1. **Redis 密码**: 如果 Redis 密码已更改，请更新解锁脚本中的密码
2. **Redis 地址**: 如果 Redis 不在本地，请更新脚本中的主机地址
3. **配置生效**: 修改配置后需要重启应用才能生效
4. **锁定时间**: 建议将 `lockTime` 设置为 10-30 分钟，既保证安全性又不会过度影响用户体验

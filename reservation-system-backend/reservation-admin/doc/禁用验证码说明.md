# 禁用登录验证码说明

## 已完成的修改

### 1. 代码修改

已修改 `SysLoginService.java` 文件：
- **文件位置**：`reservation-framework/src/main/java/com/website/framework/web/service/SysLoginService.java`
- **修改内容**：
  - 注释掉了 `login()` 方法中的验证码校验调用
  - 修改了 `validateCaptcha()` 方法，直接返回，不执行任何验证

### 2. 数据库配置（可选）

已创建 SQL 脚本 `disable-captcha.sql`，用于在数据库中禁用验证码配置。

## 使用方法

### 方法一：仅使用代码修改（推荐，已生效）

代码已经修改完成，**重启应用后即可生效**，无需执行 SQL。

**优点**：
- 立即生效，不依赖数据库配置
- 彻底禁用，即使数据库配置为开启也不会检查验证码

### 方法二：同时更新数据库配置（可选）

如果你想在系统配置中也禁用验证码（方便以后通过界面管理），可以执行：

```bash
# 连接到数据库
mysql -h 127.0.0.1 -P 3306 -u root -p reservation-system

# 执行 SQL 脚本
source disable-captcha.sql;
```

或者直接执行：
```bash
mysql -h 127.0.0.1 -P 3306 -u root -pNiubiSPA reservation-system < disable-captcha.sql
```

## 前端修改（可选）

如果前端仍然显示验证码输入框，你可能需要修改前端代码：

**文件位置**：`reservation-system-front/src/views/login.vue`

**修改方式**：
1. 检查验证码相关的 UI 元素
2. 根据后端返回的 `captchaEnabled` 字段隐藏验证码输入框
3. 或者直接注释掉验证码相关的代码

**注意**：由于后端已经禁用了验证码验证，即使前端显示验证码输入框，也可以留空或输入任意值，不会影响登录。

## 恢复验证码（如果需要）

如果以后需要重新启用验证码：

### 1. 恢复代码

在 `SysLoginService.java` 中：
- 取消注释 `validateCaptcha()` 调用
- 恢复 `validateCaptcha()` 方法的原始实现

### 2. 更新数据库配置

```sql
UPDATE sys_config 
SET config_value = 'true' 
WHERE config_key = 'sys.account.captchaEnabled';
```

### 3. 重启应用

## 注意事项

1. **安全性**：禁用验证码会降低系统的安全性，建议：
   - 确保密码强度足够
   - 考虑启用其他安全措施（如 IP 白名单、登录频率限制等）

2. **缓存**：如果修改了数据库配置，可能需要：
   - 重启应用以清除 Redis 缓存
   - 或手动清除 Redis 中的配置缓存

3. **前端**：前端可能仍会显示验证码输入框，但不影响登录功能。

## 常见问题

### Q: 修改后仍然需要输入验证码？
A: 请确保：
1. 应用已重启

A: 这是正常的，因为前端代码未修改。验证码输入框可以留空，不会影响登录。

### Q: 如何完全隐藏前端的验证码？
A: 需要修改前端代码 `login.vue`，根据 `captchaEnabled` 字段隐藏验证码相关元素。

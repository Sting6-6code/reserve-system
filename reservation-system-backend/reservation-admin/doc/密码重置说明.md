# 密码重置指南

## 问题诊断结果

根据日志分析：
- ✅ 用户存在：`userId=1, userName=admin, status=0, delFlag=0`
- ✅ 密码格式正确：BCrypt 格式，60 字符，前缀 `$2a$10$`
- ❌ **密码验证失败**：输入的密码与数据库中的密码不匹配

## 解决方案

### 方法一：使用 Java 工具生成密码哈希（推荐）

#### 步骤1：创建临时测试类

在项目中创建一个临时的测试类或使用现有的工具类：

```java
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;

public class PasswordGenerator {
    public static void main(String[] args) {
        String newPassword = "admin123";  // 设置新密码
        BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();
        String hash = encoder.encode(newPassword);
        System.out.println("新密码: " + newPassword);
        System.out.println("BCrypt 哈希: " + hash);
        System.out.println();
        System.out.println("执行以下 SQL:");
        System.out.println("UPDATE sys_user SET password = '" + hash + "' WHERE user_name = 'admin';");
    }
}
```

#### 步骤2：运行生成哈希

在 IDE 中运行 `PasswordGenerator.main()` 方法，或使用 Maven：

```bash
mvn exec:java -Dexec.mainClass="PasswordGenerator" -Dexec.classpathScope=test
```

#### 步骤3：执行 SQL 更新密码

```sql
USE reservation-system;

-- 将 <生成的哈希> 替换为步骤2生成的哈希值
UPDATE sys_user 
SET password = '<生成的哈希>' 
WHERE user_name = 'admin';

-- 验证更新
SELECT user_name, LEFT(password, 20) as password_preview 
FROM sys_user 
WHERE user_name = 'admin';
```

### 方法二：使用在线 BCrypt 生成器（临时方案）

1. 访问在线 BCrypt 生成器（如：https://www.bcrypt-generator.com/）
2. 输入新密码（如：`admin123`）
3. 复制生成的哈希值
4. 执行 SQL 更新

**注意**：在线工具可能不安全，仅用于紧急情况。

### 方法三：通过数据库直接重置（如果知道原始密码）

如果你记得原始密码，可以：

1. 使用 Java 代码验证原始密码是否正确：
```java
BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();
boolean matches = encoder.matches("原始密码", "数据库中的哈希");
System.out.println("密码匹配: " + matches);
```

2. 如果匹配，说明密码确实正确，可能是其他问题
3. 如果不匹配，使用新密码重新生成哈希并更新

## 快速重置步骤（推荐）

### 1. 生成新密码的 BCrypt 哈希

在项目根目录创建临时文件 `GeneratePassword.java`：

```java
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;

public class GeneratePassword {
    public static void main(String[] args) {
        String password = args.length > 0 ? args[0] : "admin123";
        BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();
        String hash = encoder.encode(password);
        System.out.println("密码: " + password);
        System.out.println("哈希: " + hash);
        System.out.println("\nSQL:");
        System.out.println("UPDATE sys_user SET password = '" + hash + "' WHERE user_name = 'admin';");
    }
}
```

编译并运行：
```bash
# 确保在项目根目录
javac -cp "reservation-common/target/classes:$(find . -name 'spring-security-crypto*.jar' | head -1)" GeneratePassword.java
java -cp ".:reservation-common/target/classes:$(find . -name 'spring-security-crypto*.jar' | head -1)" GeneratePassword admin123
```

### 2. 执行 SQL 更新

```sql
-- 连接到数据库
mysql -h 127.0.0.1 -P 3306 -u root -p reservation-system

-- 执行更新（替换 <哈希值> 为步骤1生成的哈希）
UPDATE sys_user 
SET password = '<哈希值>' 
WHERE user_name = 'admin';
```

### 3. 清除登录锁定（如果需要）

```bash
./unlock-account.sh admin
```

### 4. 测试登录

使用新密码登录系统。

## 验证密码是否正确

重置后，可以使用以下 SQL 验证：

```sql
-- 查看密码信息
SELECT 
    user_name,
    LEFT(password, 20) as password_preview,
    LENGTH(password) as password_length,
    CASE 
        WHEN password LIKE '$2%' THEN '✓ BCrypt 格式'
        ELSE '✗ 格式异常'
    END as format_check
FROM sys_user 
WHERE user_name = 'admin';
```

## 常见问题

### Q: 为什么不能直接在 SQL 中生成 BCrypt 哈希？
A: BCrypt 是单向哈希算法，需要使用 Java 的 `BCryptPasswordEncoder` 来生成。SQL 无法直接生成。

### Q: 重置密码后仍然无法登录？
A: 请检查：
1. 密码哈希是否正确更新
2. 是否清除了登录锁定记录
3. 应用是否已重启（某些配置可能需要重启）
4. 查看应用日志中的详细错误信息

### Q: 如何确认密码是否正确？
A: 可以使用以下 Java 代码验证：
```java
BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();
boolean matches = encoder.matches("输入的密码", "数据库中的哈希");
```

## 安全建议

1. **重置后立即登录**：重置密码后立即登录并修改为强密码
2. **不要使用默认密码**：避免使用 `admin123` 等弱密码
3. **定期更换密码**：建议定期更换管理员密码
4. **记录密码**：在安全的地方记录新密码，避免再次丢失

# 快速重置密码指南

## 问题确认

根据日志分析，问题已确认：
- ✅ 用户存在且状态正常
- ✅ 密码格式正确（BCrypt）
- ❌ **密码不匹配**：输入的密码与数据库中的密码不一致

## 最快解决方案（3步）

### 步骤1：生成新密码的 BCrypt 哈希

在 IDE 中打开并运行：
```
reservation-admin/src/main/java/com/website/web/util/PasswordGeneratorUtil.java
```

**运行方式：**
1. 在 IDE 中右键点击 `PasswordGeneratorUtil.java`
2. 选择 "Run 'PasswordGeneratorUtil.main()'"
3. 或者修改 `main` 方法中的默认密码，然后运行

**或者通过命令行：**
```bash
cd reservation-system-backend
mvn compile exec:java -Dexec.mainClass="com.website.web.util.PasswordGeneratorUtil" -Dexec.args="admin123 admin"
```

**输出示例：**
```
==========================================
密码生成工具
==========================================
用户名: admin
新密码: admin123
BCrypt 哈希: $2a$10$xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
==========================================

请执行以下 SQL 来重置密码：

USE reservation-system;
UPDATE sys_user SET password = '$2a$10$...' WHERE user_name = 'admin';
```

### 步骤2：执行 SQL 更新密码

```sql
-- 连接到数据库
mysql -h 127.0.0.1 -P 3306 -u root -p reservation-system

-- 执行更新（将 <哈希值> 替换为步骤1生成的完整哈希值）
UPDATE sys_user 
SET password = '<步骤1生成的完整哈希值>' 
WHERE user_name = 'admin';

-- 验证更新
SELECT user_name, LEFT(password, 20) as password_preview 
FROM sys_user 
WHERE user_name = 'admin';
```

### 步骤3：清除登录锁定（如果需要）

```bash
cd reservation-system-backend
./unlock-account.sh admin
```

### 步骤4：使用新密码登录

现在可以使用新密码（如：`admin123`）登录系统了。

## 验证密码是否正确

如果想验证某个密码是否与数据库中的哈希匹配，可以创建一个简单的测试：

```java
import com.website.web.util.PasswordGeneratorUtil;

public class VerifyPassword {
    public static void main(String[] args) {
        String rawPassword = "admin123";  // 输入的密码
        String dbHash = "$2a$10$7JB720uubVSVvNGzQkt5yO1w75hZ1TMuOrJ1GK.joVx9Ex8TN60e";  // 数据库中的哈希
        
        boolean matches = PasswordGeneratorUtil.verifyPassword(rawPassword, dbHash);
        System.out.println("密码匹配: " + matches);
    }
}
```

## 常见问题

### Q: 运行工具类时找不到类？
A: 确保项目已编译：
```bash
mvn clean compile
```

### Q: 生成的哈希值很长，复制时容易出错？
A: 建议：
1. 直接从控制台复制完整输出
2. 或者使用 SQL 文件，将哈希值写入文件后执行

### Q: 更新密码后仍然无法登录？
A: 检查：
1. ✅ 密码哈希是否正确更新（执行验证 SQL）
2. ✅ 是否清除了登录锁定（运行 unlock-account.sh）
3. ✅ 应用是否已重启
4. ✅ 查看应用日志确认具体错误

### Q: 如何确认当前数据库中的密码哈希？
A: 执行以下 SQL：
```sql
SELECT 
    user_name,
    password as full_hash,
    LEFT(password, 20) as hash_preview,
    LENGTH(password) as hash_length
FROM sys_user 
WHERE user_name = 'admin';
```

## 安全提示

⚠️ **重要**：
1. 重置密码后，请立即登录并修改为强密码
2. 不要在代码中硬编码密码
3. 生产环境重置密码后，建议重启应用
4. 记录新密码在安全的地方

## 一键重置脚本（高级）

如果你想自动化整个过程，可以创建一个脚本：

```bash
#!/bin/bash
# 一键重置密码脚本

NEW_PASSWORD="${1:-admin123}"
USERNAME="${2:-admin}"

echo "生成密码哈希..."
HASH=$(mvn -q exec:java -Dexec.mainClass="com.website.web.util.PasswordGeneratorUtil" -Dexec.args="$NEW_PASSWORD $USERNAME" 2>&1 | grep "BCrypt 哈希:" | awk '{print $3}')

echo "更新数据库..."
mysql -h 127.0.0.1 -P 3306 -u root -pNiubiSPA reservation-system <<EOF
UPDATE sys_user SET password = '$HASH' WHERE user_name = '$USERNAME';
EOF

echo "清除登录锁定..."
./unlock-account.sh $USERNAME

echo "完成！新密码: $NEW_PASSWORD"
```

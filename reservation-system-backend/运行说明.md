# 后端项目运行说明

## 方式一：使用 Maven 直接运行（推荐，适合开发环境）

### Mac/Linux 系统：
```bash
# 方式1：进入 reservation-admin 目录运行（推荐）
cd /Users/zifanchen/Documents/预约系统/reservation-system-backend/reservation-admin
mvn clean spring-boot:run

# 方式2：从根目录运行（需要先编译依赖）
cd /Users/zifanchen/Documents/预约系统/reservation-system-backend
mvn clean install -DskipTests
cd reservation-admin
mvn spring-boot:run
```

### Windows 系统：
```cmd
# 方式1：进入 reservation-admin 目录运行（推荐）
cd D:\预约系统\reservation-system-backend\reservation-admin
mvn clean spring-boot:run

# 方式2：从根目录运行（需要先编译依赖）
cd D:\预约系统\reservation-system-backend
mvn clean install -DskipTests
cd reservation-admin
mvn spring-boot:run
```

**参数说明：**
- `clean`: 清理之前的编译文件
- `spring-boot:run`: 使用 Spring Boot Maven 插件运行
- `install`: 安装到本地仓库（编译所有依赖模块）
- `-DskipTests`: 跳过测试

## 方式二：先打包再运行（适合生产环境）

### 步骤1：打包项目
```bash
# Mac/Linux
cd /Users/zifanchen/Documents/预约系统/reservation-system-backend
mvn clean package -DskipTests

# Windows
cd D:\预约系统\reservation-system-backend
mvn clean package -DskipTests
```

### 步骤2：运行jar文件

**Mac/Linux：**
```bash
# 进入jar文件所在目录
cd reservation-admin/target

# 运行jar文件
java -jar reservation-admin.jar

# 或者使用项目提供的脚本（需要先打包）
cd ../..
chmod +x ry.sh
./ry.sh start
```

**Windows：**
```cmd
# 进入jar文件所在目录
cd reservation-admin\target

# 运行jar文件
java -jar reservation-admin.jar

# 或者使用项目提供的脚本（需要先打包）
cd ..\..\bin
run.bat
```

## 方式三：使用IDE运行（IntelliJ IDEA / Eclipse）

1. 打开项目根目录的 `pom.xml`
2. 找到 `ReservationSystemApplication` 主类（位于 `reservation-admin/src/main/java/com/website/ReservationSystemApplication.java`）
3. 右键点击主类，选择 "Run" 或 "Debug"

## 常见问题

### 1. Maven 未安装
如果提示 `mvn: command not found`，需要先安装 Maven：
- Mac: `brew install maven`
- Linux: `sudo apt-get install maven` 或 `sudo yum install maven`
- Windows: 下载并配置 Maven 环境变量

### 2. Java 版本问题
确保 Java 版本为 1.8（JDK 8）：
```bash
java -version
```

### 3. 端口被占用
如果 8081 端口被占用，可以修改 `reservation-admin/src/main/resources/application.yml` 中的端口：
```yaml
server:
  port: 8082  # 改为其他端口
```

### 4. 数据库连接问题
确保 MySQL 数据库已启动，并检查 `application-druid.yml` 中的数据库配置。

## 停止服务

### 方式一：如果使用 Maven 运行
按 `Ctrl + C` 停止

### 方式二：如果使用 jar 运行
```bash
# Mac/Linux
./ry.sh stop

# 或查找进程并杀死
ps aux | grep reservation-admin.jar
kill -9 <进程ID>
```

## 查看日志

日志文件位置：
- Mac/Linux: `logs/reservation-admin.jar.log`
- Windows: `logs\reservation-admin.jar.log`

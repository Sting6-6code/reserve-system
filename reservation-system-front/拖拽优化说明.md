# 首页模块拖拽优化说明

## 问题描述

首页分为上下两个模块，通过拖拽中间的拖拽线可以调整两个模块的高度。但是存在以下问题：
- 拖拽后页面会突然跳一大截
- 无法停留在鼠标停留的位置
- 拖拽体验不流畅

## 问题原因分析

### 原始代码的问题

1. **错误的距离计算**：
   ```javascript
   let top = e.clientY-event.clientY  // 错误：应该是 event.clientY - e.clientY
   ```

2. **使用当前高度计算**：
   - 每次拖拽时都使用 `getBoundingClientRect()` 获取当前高度
   - 当高度改变后，获取的值会变化，导致计算不准确
   - 造成累积误差，导致跳转

3. **没有禁用过渡动画**：
   - CSS 中有过渡动画（transition）
   - 拖拽时动画会造成延迟，导致位置不准确

## 优化方案

### 1. 记录初始状态 ✅
- 在拖拽开始时记录初始鼠标位置和初始容器高度
- 使用初始值进行计算，而不是每次获取当前值

### 2. 正确的距离计算 ✅
- 使用 `event.clientY - startY` 计算鼠标移动距离
- 根据初始高度 + 移动距离计算新高度

### 3. 禁用拖拽时的过渡动画 ✅
- 拖拽时添加 `dragging` 类
- CSS 中设置 `.dragging` 类禁用过渡动画
- 拖拽结束后移除类，恢复动画

### 4. 改进边界处理 ✅
- 更精确的高度限制（100-700px）
- 超出范围时正确计算总高度

## 代码修改详情

### 修改1：优化拖拽逻辑

**修改前**：
```javascript
let top = e.clientY-event.clientY  // 错误
let realTopHeight=container_top_rect.height-last_top  // 使用当前高度
let realBottomHeight=container_bottom_rect.height+last_top
```

**修改后**：
```javascript
// 记录初始状态
const startY = e.clientY
const startTopHeight = container_top.getBoundingClientRect().height
const startBottomHeight = container_bottom.getBoundingClientRect().height

// 计算移动距离
const deltaY = event.clientY - startY

// 根据初始高度计算新高度
let newTopHeight = startTopHeight + deltaY
let newBottomHeight = startBottomHeight - deltaY
```

### 修改2：添加拖拽类控制动画

**JavaScript**：
```javascript
// 拖拽开始时
container_top.classList.add('dragging')
container_bottom.classList.add('dragging')

// 拖拽结束时
container_top.classList.remove('dragging')
container_bottom.classList.remove('dragging')
```

**CSS**：
```css
/* 拖拽时禁用过渡动画 */
#container-top.dragging{transition: none !important}
#container-bottom.dragging{transition: none !important}
/* 正常状态下的过渡动画 */
#container-top{transition: height .1s ease-in-out}
#container-bottom{transition: height .1s ease-in-out}
```

## 优化效果

### 优化前
- ❌ 拖拽时页面会跳转
- ❌ 无法精确停留在鼠标位置
- ❌ 拖拽体验差

### 优化后
- ✅ 拖拽流畅，无跳转
- ✅ 精确跟随鼠标位置
- ✅ 拖拽体验良好

## 技术细节

### 拖拽方向说明
- **向上拖动**（鼠标向上移动，`deltaY < 0`）：
  - 顶部模块变小（`newTopHeight = startTopHeight + deltaY`，deltaY为负）
  - 底部模块变大（`newBottomHeight = startBottomHeight - deltaY`，减去负数等于加正数）

- **向下拖动**（鼠标向下移动，`deltaY > 0`）：
  - 顶部模块变大（`newTopHeight = startTopHeight + deltaY`，deltaY为正）
  - 底部模块变小（`newBottomHeight = startBottomHeight - deltaY`，减去正数）

### 高度限制
- 顶部模块：100px - 700px
- 底部模块：自动调整，保持总高度不变
- 超出范围时，设置为边界值

   - 只修改了拖拽相关的代码
   - 其他功能保持不变

2. **浏览器兼容性**：
   - 使用了标准的 DOM API
   - 兼容现代浏览器

3. **性能优化**：
   - 拖拽时禁用动画提升性能
   - 使用初始值避免重复计算

## 总结

通过记录初始状态、正确计算移动距离、禁用拖拽时的过渡动画，成功解决了拖拽跳转的问题。现在拖拽功能可以精确跟随鼠标位置，提供流畅的用户体验。
